## About

I'm a Software Engineer interested in building reliable software, exploring modern architectures, and leveraging Artificial Intelligence to improve how software is designed, developed, and maintained.

My professional experience includes developing high-scale mobile products within the Apple ecosystem, working with Swift and engineering practices focused on maintainability, scalability, and code quality.

Today, my interests extend beyond traditional software development, particularly toward **AI-Assisted Development, Agentic Engineering, LLM ecosystems, and intelligent automation**.

I enjoy understanding how things work beneath the interface, making architectural decisions, and transforming technical concepts into practical solutions.
